Flujo profesional para iniciar y subir proyectos

Command Line GitHub Flow Best Practices
01

Inicializar proyecto

# Crear carpeta y entrar
mkdir proyecto-git
cd proyecto-git
# Inicializar repositorio Git
git init
Se crea la carpeta oculta .git con toda la configuración
02

Primer commit local

git add .
git commit -m "proyecto base"
git status
Añade todos los archivos al staging Crea punto de control
03

Crear repositorio en GitHub

Crea un repositorio remoto desde GitHub (sin README, .gitignore ni licencia) si ya tienes un proyecto local.

→ New repository → Nombra tu repositorio → Create repository
04

Vincular repositorio remoto

git remote add origin https://github.com/tuusuario/repo.git
Conecta el repositorio local con el remoto (origin)
05

Primer push

git push -u origin master
-u establece seguimiento upstream Sube la rama master a origin

Actualizaciones posteriores

git add .
git commit -m "MENSAJE DESCRIPTIVO"
git push origin master
Flujo diario: add → commit → push

Usa git branch feature para aislar cambios
